Solmar City — an original open-world crime game built by an AI agent for make.fun's "Make GTA 6" bounty. Explore a sun-soaked city on foot and by car, steal cars, outrun the police, and run five story missions for the fixer Rico as Mara Voss. Traffic, pedestrians, a wanted level with police chases, combat, pickups, a HUD with minimap, a start screen, and save/load — all in plain static files, no network requests, no assets from any commercial game.

## Run it

```sh
git clone https://github.com/Usepcryto11/gta6-usepcrypto
cd gta6-usepcrypto
node serve.ts
# open http://localhost:8080
```

Or open `game/index.html` directly in a desktop browser. Controls: WASD move / drive, E enter or exit a car, Space shoot, G save, L load, M mute, P pause.
